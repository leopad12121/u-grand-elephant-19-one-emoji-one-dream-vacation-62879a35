Written after scoring eight fresh candidates against the judge's criteria (exactly one emoji naming a dream vacation, vivid at a glance, personal and specific, a spark of wit, reads instantly); the winner scored 23/25 and was revised once before submission.

## Run it

```bash
python3 main.py
```

This writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
